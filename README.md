🐾 Dashboard de Business Intelligence para Pet Shop – Gatitos
📌 Visão Geral
Neste projeto, fomos contratados pela Helô, proprietária do pet shop Gatitos, para implementar um processo de Business Intelligence (BI). Com planos de expansão, ela precisa tomar decisões estratégicas baseadas em dados — e é aí que entramos com uma solução desenvolvida no Power BI. 💼📊

🎯 Objetivo do Projeto
Implementar um processo de BI completo, desde a importação dos dados até a entrega de dashboards estilizados e interativos, permitindo que a Helô tome decisões mais embasadas e seguras para o crescimento do seu negócio.

🧠 O que foi feito
Durante o desenvolvimento do projeto, aplicamos conceitos essenciais do BI e utilizamos recursos do Power BI para:

📥 Importar dados de diferentes formatos (Excel, CSV, etc.)

🧹 Tratar e transformar dados com Power Query

📤 Carregar os dados no modelo Power BI

➕ Criar colunas calculadas e medidas utilizando DAX

📊 Desenvolver visuais personalizados para análise

🎨 Aplicar estilização profissional nos dashboards para entrega visual clara e intuitiva


🌟 Destaques
Projeto realista com aplicação prática de BI 💼

Visualizações otimizadas para tomada de decisão 🧠

Foco em clareza, performance e experiência do usuário 🖥️

Aprendizado de DAX e manipulação de dados com Power Query 📐

🚀 Tecnologias Utilizadas
Microsoft Power BI

Power Query

DAX (Data Analysis Expressions)
